Assessment em destaque

API Security Assessment · Food-Delivery SaaS

AUTORIZADO · SANITIZADO
2026 · Go / Gin REST API · 130 rotas · 3 perfis

Pentest completo em uma API de delivery: inventário de rotas pelo código-fonte, teste em runtime com os 3 perfis (cliente, loja, admin) e cobertura integral do OWASP Top 10.

  • 2 High (CVSS 8.8 / 8.1): bugs de negócio que scanner não acha: escalada de role no POST /store e duplicação massiva de CNPJ (provada com burst paralelo).
  • 0 críticos · sem IDOR · sem injeção: JWT, RBAC, upload (decode-validation) e CORS testados ativamente e validados.
  • Entrega profissional: relatório de 25 páginas, mapeamento CVSS/CWE/OWASP/ATT&CK e roadmap 7/30/60/90 com donos.
  • Sanitização total: edição pública sem expor o cliente, confidencialidade sob NDA.

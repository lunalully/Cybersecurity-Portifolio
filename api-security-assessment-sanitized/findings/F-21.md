# F-21 — XFF / Host Header Sem Bypass (Controle Positivo)

- **Severidade:** INFO
- **CWE:** — (defesa validada)
- **OWASP 2021:** A07 — Identification and Authentication Failures

## Descrição
Duas tentativas de spoofing contra o rate limiter e o host virtual foram **bloqueadas**:

- `POST /login` com `X-Forwarded-For` rotativo `1.1.1.1…1.1.1.12` → ainda `429` após o
  limite (o limiter chaveia no IP real / header de proxy confiável, não no XFF bruto).
- `GET /health` com `Host: evil.com | localhost | 127.0.0.1` → `404` (vhost estrito; sem
  injeção de Host-header).

Este é um controle positivo confirmando que o rate limiter não pode ser trivialmente burlado
por spoofing e que o servidor não roteia por valores de Host não confiáveis.

## Evidência (sanitizada)
```
12 × POST /login (X-Forwarded-For 1.1.1.{1..12}) → 6×401 depois 429
GET /health Host: evil.com → 404
```

## Remediação
Nenhuma — o comportamento está correto. Manter a fronteira de confiança do XFF (confiar
apenas no XFF adicionado pela CDN) e adicionar um teste de regressão para travá-lo.

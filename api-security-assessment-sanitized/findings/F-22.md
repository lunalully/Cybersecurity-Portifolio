# F-22 — Escaneamento Automatizado Não Encontrou Exposição Adicional (Controle Positivo)

- **Severidade:** INFO
- **CWE:** — (defesa validada)
- **OWASP 2021:** A05 — Security Misconfiguration

## Descrição
Ferramentas ofensivas foram executadas contra a API para validar os achados manuais e procurar
superfície oculta:

- **ffuf** (dicionário de 38 paths): apenas `/health` retornou `200` — sem rotas ocultas,
  `.env`, `.git`, arquivos de backup ou endpoints de debug.
- **Nuclei** (`http/misconfiguration`, `exposures`, `cves`): apenas
  `http-missing-security-headers` (info) — zero achados HIGH/CRITICAL.
- Sem Swagger/`/docs`/GraphQL/Actuator expostos; `/.well-known/security.txt` ausente.

Isso confirma que a superfície de ataque se limita às rotas documentadas e que os achados
identificados são o conjunto completo para este ciclo de engajamento.

## Evidência (sanitizada)
```
ffuf /FUZZ (38 words) → 200 apenas em /health
nuclei http/misconfiguration → 4 missing-security-headers (apenas info)
nuclei http/exposures + cves → 0 HIGH/CRITICAL
```

## Remediação
Manter escaneamentos automatizados no CI (templates Nuclei/ffuf) para que novas rotas sejam
re-validadas por release; publicar `security.txt` e um SBOM público.

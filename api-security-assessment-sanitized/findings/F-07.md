# F-07 — Webhook de Loja Vaza Existência de Loja (404 vs 401)

- **Severidade:** LOW
- **CVSS v3.1:** 3.7 (AV:N/AC:H/PR:N/UI:N/S:U/C:L/I:N/A:N)
- **CWE:** CWE-200 (Exposição de Informação Sensível)
- **OWASP 2021:** A01 — Broken Access Control
- **MITRE ATT&CK:** T1046 — Network Service Discovery

---

## Descrição

`POST /webhooks/{storeId}` executa o lookup de configuração de pagamento **antes** de validar
a assinatura do `asaas-access-token`. Para uma loja sem configuração de pagamento retorna
`404 store payment config not found`; para um payload não autenticado no webhook da
plataforma retorna `401 invalid webhook signature`. Essa resposta diferencial permite que um
atacante não autenticado distinga "loja não existe / sem config" de "loja existe",
possibilitando enumeração.

## Evidência (sanitizada)

```http
POST /webhooks/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx HTTP/1.1
Host: api.example.com
Content-Type: application/json
{}                             # sem header asaas-access-token
```

```http
HTTP/1.1 404 Not Found
{"error":"store payment config not found"}
```

vs. webhook de billing:

```http
POST /webhooks/billing HTTP/1.1
Content-Type: application/json
{}
```

```http
HTTP/1.1 401 Unauthorized
{"error":"invalid webhook signature"}
```

## Remediação

Validar a assinatura do `asaas-access-token` **antes** de qualquer lookup no banco e sempre
retornar um `401 invalid webhook signature` genérico em falha, independentemente do estado
da loja.

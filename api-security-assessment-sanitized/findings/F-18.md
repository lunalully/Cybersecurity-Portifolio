# F-18 — Strings Tipo Path-Traversal Armazenadas Literalmente em `name`

- **Severidade:** INFO
- **CWE:** CWE-22 (Path Traversal) — observado apenas como literal armazenado, sem traversal
- **OWASP 2021:** A03 — Injection

## Descrição
`PATCH /user/profile` aceita e armazena `"name":"../../../etc/passwd"` literalmente (200).
Não ocorre path traversal porque o valor é usado apenas como texto de exibição, nunca como
caminho de arquivo. É anotado como questão de higiene: se o nome for usado algum dia em
contexto de filesystem ou URL, vira vetor de traversal.

## Evidência (sanitizada)
```
PATCH /user/profile {"name":"../../../etc/passwd"} → 200 (armazenado literalmente)
```

## Remediação
Normalizar/rejeitar sequências tipo path em `name` (`../`, `/`, `\`) ou apenas aplicar
whitelist de exibição. Adicionar o check junto com a sanitização do F-03.

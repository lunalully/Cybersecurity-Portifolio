# F-17 — Grupos Internos do Catálogo Visíveis a Customers

- **Severidade:** INFO
- **CWE:** CWE-200 (Exposição de Informação Sensível)
- **OWASP 2021:** A01 — Broken Access Control

## Descrição
`GET /store/{id}/addon-groups` e `GET /store/{id}/variant-groups` retornam dados a qualquer
`customer` autenticado (200), enquanto o inventário as marcou como orientadas à gestão.
`GET /store/{id}/payment-methods` retornou 404 (não semeadas). Se esses grupos são recursos
internos de gestão de menu, deveriam ser restritos a `store_owner`.

## Evidência (sanitizada)
```
GET /store/{id}/addon-groups   customer → 200 | store_owner → 200 | anônimo → 401
GET /store/{id}/variant-groups customer → 200 | store_owner → 200 | anônimo → 401
```

## Remediação
Decidir a audiência pretendida; se for só gestão, aplicar `store_owner` e adicionar um teste.

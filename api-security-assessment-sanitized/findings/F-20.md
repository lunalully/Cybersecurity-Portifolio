# F-20 — Delete de Avatar Idempotente Retorna 200

- **Severidade:** INFO
- **CWE:** CWE-690 (Condição de Erro Não Verificada)
- **OWASP 2021:** A05 — Security Misconfiguration

## Descrição
`DELETE /user/avatar` retorna `200` para as roles `customer` e `store` mesmo quando não existe
avatar — a operação é idempotente. Nenhum IDOR foi observado (usuários só deletam o próprio
avatar). Isso é aceitável, mas deveria ser documentado para que clientes esperem `200` em
"já deletado".

## Evidência (sanitizada)
```
DELETE /user/avatar (customer, sem avatar) → 200
DELETE /user/avatar (store, sem avatar)    → 200
```

## Remediação
Documentar a semântica idempotente no contrato da API (ou retornar `204 No Content` em delete
bem-sucedido independentemente da existência).

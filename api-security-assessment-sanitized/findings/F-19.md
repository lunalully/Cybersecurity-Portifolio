# F-19 — Validação Fraca de Tamanho de Nome (1 Char)

- **Severidade:** INFO
- **CWE:** CWE-20 (Validação de Entrada Impropria)
- **OWASP 2021:** A04 — Insecure Design

## Descrição
`PATCH /user/profile` aceita um nome de 1 caractere (`"A"`) com `200`. Strings vazias são
rejeitadas, mas não há tamanho mínimo, habilitando spam de perfil e nomes placeholder triviais.
Não há risco de overflow (nomes de 100 chars são ok).

## Evidência (sanitizada)
```
PATCH /user/profile {"name":"A"} → 200
PATCH /user/profile {"name":""}  → 400 name must not be empty
PATCH /user/profile {"name":"A"×100} → 200
```

## Remediação
Aplicar `2 ≤ len(name) ≤ 100` (com trim de whitespace) e retornar `400` com mensagem clara.

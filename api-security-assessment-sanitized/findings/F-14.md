# F-14 — API Exposta Sem Edge WAF / Proteção CDN

- **Severidade:** INFO
- **CWE:** CWE-693 · **OWASP 2021:** A05 — Security Misconfiguration
- **MITRE ATT&CK:** T1190 — Exploit Public-Facing Application

## Descrição
Os front-ends web estão atrás de uma CDN com challenges gerenciados, mas a API é exposta
diretamente: IP de origem direto, sem headers `cf-ray`/CDN, sem edge WAF, sem rate limiting
na borda. Não há achados exploráveis conhecidos na API hoje, mas a borda é o lugar mais
barato para absorver ataques volumétricos, filtrar CVEs conhecidos e fornecer rate limits por IP.

## Evidência (sanitizada)
```
GET /health → 200, headers da resposta SEM headers de CDN (sem cf-ray, sem server: cloudflare)
fronts: 307 + JS challenge (cf_chl_*) → CDN presente
```

## Remediação
Fazer proxy da API pela CDN/WAF também; aplicar rate limits por IP na borda; manter acesso de
origem direta bloqueado.

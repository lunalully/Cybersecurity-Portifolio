# F-16 — Customer Pode Auto-Pedir na Própria Loja

- **Severidade:** INFO
- **CWE:** CWE-841 (Aplicação Impropria de Workflow Comportamental)
- **OWASP 2021:** A04 — Insecure Design

## Descrição
Um customer que escalou para `store_owner` (F-01) pode criar um pedido contra a própria loja:
`POST /store/{ownStoreId}/order` retornou `200` com um pedido `CREATED`. Se pedir na própria
loja é contra as regras de negócio, não há guarda verificando
`order.user_id == store.owner_id`.

## Evidência (sanitizada)
```
POST /store/xxxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx/order (customer, própria loja) → 200 CREATED 9ae2fb…
```

## Remediação
Esclarecer a regra. Se auto-pedido for proibido, adicionar um check rejeitando o dono como
customer da própria loja.
